A fast drop-in for csv-reader 1.0.0: reads broken CSV files with byte-identical answers. Minimal-cold parser — half the code of the first version, with lazy rare-case paths, so a fresh container compiles less before the first case. Pure Node.js standard library, no dependencies.

## Run it

```sh
MAKEFUN_INPUT_DIR=<input-dir> MAKEFUN_OUTPUT_DIR=<output-dir> node main.ts
```
